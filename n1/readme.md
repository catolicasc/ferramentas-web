# 🎨 Trabalho em Grupo – Fundamentos do CSS

## 📌 Objetivo
Os grupos deverão criar uma **página web estática** utilizando **HTML + CSS**, aplicando os conceitos de **cores, tipografia, layout, imagens, links, animações e consistência visual**.

---

## 🔹 Temas Disponíveis
Cada grupo deve escolher um dos temas abaixo para desenvolver sua página:

1. **🐶 Site de Pet Shop**
   - Apresentação de serviços como banho, tosa e produtos para animais.
   - Seções como "Serviços", "Produtos" e "Contato".
   - Uso de cores suaves e fontes amigáveis.

2. **🛍️ Site de Loja Virtual (E-commerce)**
   - Exibição de produtos fictícios com imagens e preços.
   - Botões de "Adicionar ao Carrinho" estilizados.
   - Uso de cores para destacar promoções.

3. **🍔 Site de Restaurante/Lanchonete**
   - Menu digital com imagens e descrições dos pratos.
   - Seções como "Cardápio", "Sobre Nós" e "Contato".
   - Uso de tipografia chamativa e imagens atrativas.

4. **🎵 Site de Banda ou Festival de Música**
   - Divulgação de uma banda, evento ou festival musical.
   - Seções como "Shows", "Ingressos" e "Galeria de Fotos".
   - Uso de animações para destacar as informações.

5. **🚀 Site de Startup ou Tecnologia**
   - Apresentação de um produto ou serviço inovador.
   - Seções como "Nossa Solução", "Clientes" e "Depoimentos".
   - Uso de cores modernas e transições sutis.

6. **📚 Site Educacional (Curso ou Escola)**
   - Página de um curso, faculdade ou escola.
   - Seções como "Cursos Disponíveis", "Professores" e "Inscrição".
   - Uso de fontes claras e legíveis.

---

## 🎯 Requisitos do Trabalho
- Utilizar **HTML + CSS** para criar a página.
- Aplicar as seguintes técnicas:
   - **Cores e Fundos** (`background-color`, `background-image`, `rgba`, `gradients`)
   - **Textos** (`font-family`, `font-size`, `text-transform`, `letter-spacing`)
   - **Layouts e Posicionamento** (`flexbox`, `grid`, `position`)
   - **Imagens** (`object-fit`, `border-radius`, `box-shadow`)
   - **Estilos para Links** (`hover`, `visited`, `active`)
   - **Animações e Transições** (`@keyframes`, `transition`, `transform`)
   - **Consistência Visual** (padrões de cores, fontes e espaçamentos)
- O código deve ser organizado, comentado e bem estruturado.
- A apresentação do trabalho será feita em sala.
